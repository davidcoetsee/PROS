# Changelog

All notable PROS changes are recorded here.

## 1.5.1 — 2026-08-23

- Released PROS first-party source and project assets under MPL-2.0.
- Added embedded licence, exact-source, trademark, asset, and third-party legal
  information while retaining the portable one-file Windows executable.
- Added an in-app Help entry for the open-source licence and matching source.
- Excluded unused `lxml.isoschematron` resources from the executable; the PDF
  processing engine, supported formats, and performance profile are unchanged.
- Added reproducible release packaging, checksums, and Windows continuous
  integration.

## 1.5.0 — 2026-08-22

- Introduced the revised numbered workflow, native PDF drag and drop, canonical
  branding, multi-file Keep Separate processing, and the final v1.5 PDF engine
  and packaging acceptance suite.
